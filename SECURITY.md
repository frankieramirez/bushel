# Security policy

## Supported versions

Security fixes land on the latest released `bushel` version. Older tags are not patched.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

1. Prefer GitHub's **[private vulnerability reporting](https://github.com/frankieramirez/bushel/security/advisories/new)** (enable it under the repo's Security settings if the form is missing).
2. If private reporting is unavailable, contact the maintainer via GitHub (@frankieramirez) and say you have a security report — do not include exploit details in a public channel.

Include the bushel version, macOS version, `container --version`, and steps to reproduce. You should hear back within a week.

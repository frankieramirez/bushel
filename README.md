# bushel

A terminal UI for managing [Apple Containers](https://github.com/apple/container) — containers, images, and volumes from the comfort of your terminal. A bushel is a container that holds apples.

> **Status: planning.** The design is being worked out in the open on the [wayfinder map](../../issues/1) before any code lands. v0.1 will be a lazydocker-style TUI built in Rust with [Ratatui](https://github.com/ratatui/ratatui), wrapping the `container` CLI.

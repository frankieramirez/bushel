# quayside

A terminal UI for managing [Apple Containers](https://github.com/apple/container) — containers, images, and volumes from the comfort of your terminal.

> **Status: planning.** The design is being worked out in the open on the [wayfinder map](../../issues) before any code lands. v0.1 will be a lazydocker-style TUI built in Go with [Bubble Tea](https://github.com/charmbracelet/bubbletea), wrapping the `container` CLI.
